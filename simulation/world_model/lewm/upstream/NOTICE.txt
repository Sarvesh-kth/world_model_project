Paper: LeWorldModel: Stable End-to-End Joint-Embedding Predictive
Architecture from Pixels (Maes, Le Lidec, Scieur, LeCun, Balestriero, 2026)
https://arxiv.org/abs/2603.19312

Our adaptation uses these model and SIGReg implementations, constructs the
same ViT-Tiny architecture with the existing Hugging Face Transformers API,
and supplies this project's frame/action loader, scene-group splits and
PyTorch training loop. It does not copy upstream benchmark datasets,
checkpoints, environment package, training framework or reported results.
